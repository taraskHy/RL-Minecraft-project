Real-Minecraft Replays

Every run here happened on a real Minecraft 1.21.4 server, with the trained networks driving a Mineflayer bot on courses they had never seen. Each recording replays the game's own ticks (20 per second), failures included.

    Keys: space plays or pauses, left and right arrows step one tick, [ and ] change course.

    stone platform start (platform 0) goal extra stone: neo walls, beams, pillars, basins slime block water ice ladder, trapdoor, fence path while the final policy (or the one network) acts path while a skill network acts
    Data: each set's recordings come from results/games/ in the project repository (the folder names are in the facts panel), recorded by parkour.live in real Minecraft. "Same as the simulator" means the simulator's own run of the same networks on the same course from the bot's start ended the same way. The replay check re-ran the recorded actions in the simulator; the largest position difference is in the facts panel.
